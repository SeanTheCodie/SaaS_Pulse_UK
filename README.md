# SaaS_Pulse_UK
The data and stories behind the UK's SaaS, Software and Data SMEs

This service will track the UK's vibrant community of SME businesses building software, SaaS and data driven tech solutions.  Included in the data base are all UK basd businesses who;

- Turnover < £10M
- Are privately owned, invested in by Private Equity / Venture Capital, owned by portfolio building orgnisations or in corporate ownership
- UK HQ'd
- UK Companies House registered
