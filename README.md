# SaaS_Pulse_UK
The data and stories behind the UK's SaaS, Software and Data SMEs

This service will track the UK's vibrant community of SME businesses building software, SaaS and data driven tech solutions.  Included in the data base are all UK basd businesses who;

- Turnover < £10M
- Are privately owned, invested in by Private Equity / Venture Capital, owned by portfolio building orgnisations or in corporate ownership
- UK HQ'd
- UK Companies House registered

# Saas Pulse UK will have these elements

- Track the key financial metrics using data from Companies House
- Highlight whether the business is vertical or horizontal market focussed, which product/market area it build in
- Link to their website and LinkedIn profile
- Scan their website and LinkedIn profile for news stories and provide a list with links
- If they provide services to public sector customers, show how much of their revenues come from public funding
- Provide 'signals' as this data changes to highlight whathas changed from the most recently lodged financial results compared to the previous ones
- Allow users to track the financial data and signals particular businesses, receiving alerts when something changes, bringing them back to the site
- Provide indexes of 25 businesses by market, product, region, revenue ranges (<1m, 1m - 3m, 3m - 5m, 5m+)
- Allow owners to nominate their business for inclusion
- Build a monthly newsletter from the data set showing key macro trends
- Build a quartery newsletters / content by market/product areas
